1. The graph: Blantyre city road network Q1 · 15 marks

Scenario. The graph models the roads of Blantyre city, from Blantyre town (the city centre) in the west to Limbe in the east. Each vertex is a place in the city: a neighbourhood (for example Ndirande, Chilomoni, Soche, Chinyonga), a landmark (Queen Elizabeth Central Hospital, Chichiri) or a major junction (Ginnery Corner). Each edge is a road that links two places directly, without passing through another place in the graph. The weight of an edge is the road distance between the two places.

Blantyre and Limbe are joined by two main roads, and both appear in the graph. Masauko Chipembere Highway runs from the city centre past Ginnery Corner and Kanjedza to Limbe. Kamuzu Highway runs past Chichiri and Chinyonga. Smaller roads connect the residential areas around them.

The graph is undirected because the roads carry traffic in both directions, so the distance from A to B equals the distance from B to A. It is weighted because the roads have different lengths, and it is simple (no self loops, at most one road between two places).

Distances are approximate road distances, rounded to the nearest 100 m. They are stored in the data file as whole metres (for example 1500), and the program shows them in kilometres with one decimal (1.5 km). Whole numbers avoid rounding errors when distances are added.

2. Drawing and description of the graph Q2 · 10 marks

Conventions used. Each place is drawn as a circle (vertex) labelled with its name. Each road is a straight line (edge) between two circles. Because the graph is undirected, the lines have no arrowheads. The number in the box on each line is the weight, the distance in km. Places are laid out roughly as they are on a map of Blantyre, with Blantyre town on the left (west), Limbe on the right (east) and north at the top.

Description

  • Connected: there is a path between every pair of places, so G has a single component. Test T10 confirms this: all 529 source–target pairs have a finite distance.
  • Sparse: a simple graph on 23 vertices can have at most 23 × 22 / 2 = 253 edges. G has 37, a density of 37 / 253 ≈ 0.15. This is typical of road networks and is why an adjacency list is the right representation.
  • Degrees: the sum of degrees is 2|E| = 74 (handshake lemma), so the average degree is 3.22. Blantyre CBD has the highest degree (6), as the city centre where many roads meet. Ginnery Corner, the busy junction between Blantyre and Limbe, has degree 5. 6 places have degree 2: Sunnyside, Kameza, Manja, Zingwangwa, Bangwe, Machinjiri. These are at the edge of the city.
  • Cycles: G contains many cycles, for example Blantyre CBD–Mandala–QECH–Blantyre CBD (1.5 + 1.0 + 2.2 = 4.7 km) and the two highway corridors Ginnery Corner–Kanjedza–Chinyonga–Chichiri–Ginnery Corner. The cyclomatic number |E| − |V| + 1 = 15 is the number of independent cycles, and also the number of roads that can be removed while keeping all places connected (see the MST in section 6).
  • No bridges: removing any single road leaves the graph connected, because every road lies on a cycle. In practice, if one road is closed (for example for repairs) every place can still be reached by another route.
  • Longest and shortest roads: Ndirande–Machinjiri (4.5 km) is the longest. Mandala–QECH (1.0 km) is the shortest.

The assignment asks for the graph to be drawn on paper. Figure 1 is the typed version; the hand-drawn version follows the same layout and conventions.

3. How Dijkstra's algorithm works on the graph Q3 · 15 marks

Dijkstra's algorithm finds the shortest distance from one source vertex to every other vertex in a graph with non-negative weights. It keeps a tentative distance d[v] for every place, starting at 0 for the source and ∞ for the rest. At each step it settles the unsettled place with the smallest tentative distance; that distance is now final, because every other route would have to leave through a place that is already at least as far away and the weights are never negative. It then relaxes each road (u, v) out of the settled place: if d[u] + w(u, v) < d[v], it lowers d[v] and records u as the previous place on v's route.

DIJKSTRA(G, s)
  for each vertex v:  d[v] ← ∞,  prev[v] ← NIL
  d[s] ← 0;  Q ← min-priority queue containing (0, s)
  while Q is not empty:
      (du, u) ← EXTRACT-MIN(Q)
      if u is already settled: continue          // stale entry
      mark u settled
      for each edge (u, v, w):
          if v not settled and du + w < d[v]:
              d[v] ← du + w;  prev[v] ← u;  INSERT(Q, (d[v], v))

Design decisions

  • Adjacency list (vector<vector<pair<int, long long>>>): uses O(V + E) memory and lets Dijkstra visit only the real neighbours of a place. An adjacency matrix would need 23 × 23 = 529 cells for 37 roads.
  • Place names are mapped to integer IDs with a std::map, so the algorithms work on fast array indices while the user types names.
  • Distances in whole metres. Storing 1.5 km as 1500 m keeps all arithmetic in integers, so sums are exact and comparisons such as d[u] + w < d[v] never suffer from floating-point rounding. Output is converted to km.
  • Binary heap priority queue (std::priority_queue with std::greater) holding (distance, place) pairs. Instead of a decrease-key operation, a place is pushed again when its distance improves, and outdated entries are skipped when popped (“lazy deletion”). This keeps the code short and gives O((V + E) log V) time.
  • Path reconstruction uses the prev[] array, following pointers back from the target and reversing.
  • Input validation: negative weights are rejected (Dijkstra is incorrect with them), as are self loops, malformed lines, non-numeric distances, missing files and unknown place names. Unreachable places are reported as “No route”.

Core code: Dijkstra

struct DijkstraResult {
    std::vector<long long> dist;  // dist[v] = shortest distance in metres from source (INF if unreachable)
    std::vector<int> prev;        // prev[v] = previous place on the shortest path (-1 if none)
};

// One step of the algorithm, recorded for the dry run trace.
struct TraceStep {
    int settled;                                   // place removed from the queue and finalised
    long long settledDist;
    std::vector<std::tuple<int, long long, long long>> relaxed;  // (place, old dist, new dist)
};

// Dijkstra with a binary heap (std::priority_queue): O((V + E) log V).
inline DijkstraResult dijkstra(const Graph& g, int source, std::vector<TraceStep>* trace = nullptr) {
    int n = g.size();
    if (source < 0 || source >= n) throw std::out_of_range("Source index out of range");
    DijkstraResult r{std::vector<long long>(n, INF), std::vector<int>(n, -1)};
    std::vector<bool> done(n, false);
    using Item = std::pair<long long, int>;  // (distance, place)
    std::priority_queue<Item, std::vector<Item>, std::greater<Item>> pq;

    r.dist[source] = 0;
    pq.push({0, source});
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (done[u]) continue;  // stale queue entry
        done[u] = true;
        TraceStep step{u, d, {}};
        for (auto [v, w] : g.neighbours(u)) {
            if (done[v]) continue;
            if (d + w < r.dist[v]) {
                step.relaxed.emplace_back(v, r.dist[v], d + w);
                r.dist[v] = d + w;
                r.prev[v] = u;
                pq.push({r.dist[v], v});
            }
        }
        if (trace) trace->push_back(step);
    }
    return r;
}

// Rebuild the path source -> target from prev[]. Empty if unreachable.
inline std::vector<int> buildPath(const DijkstraResult& r, int target) {
    std::vector<int> path;
    if (r.dist.at(target) >= INF) return path;
    for (int v = target; v != -1; v = r.prev[v]) path.push_back(v);
    std::reverse(path.begin(), path.end());
    return path;
}

6. Does the graph have a minimum spanning tree? Q6 · 10 marks

Yes. A spanning tree is a subset of the edges that connects all the vertices with no cycles; it has exactly |V| − 1 edges. A minimum spanning tree (MST) is a spanning tree with the smallest possible total weight. An undirected graph has a spanning tree if and only if it is connected, and then it also has a minimum one, because there are finitely many spanning trees and one of them must have the smallest total. Our graph is undirected, weighted and connected (section 2), so it has an MST.

The MST of our graph has 22 edges and a total length of 39.3 km, compared with 78.0 km for all 37 roads. The other 15 roads (the cyclomatic number from section 2) each close a cycle and are not needed for connectivity.

The MST is unique. Some roads have equal lengths (for example several roads of 1.5 km and of 2.5 km), which can sometimes allow more than one MST. We checked every road that is not in the tree: in each case it is strictly longer than every road on the tree path between its two places, so no swap gives an equal total. The MST is therefore the only one.

What the MST represents

The MST is the shortest total length of road that still connects every place to every other place. In Blantyre this answers questions such as:

  • Laying pipes or cables along the roads. Blantyre Water Board pipes, ESCOM power lines and fibre-optic cables are usually laid along road reserves. Connecting all 23 places along the MST needs 39.3 km of pipe or cable instead of 78.0 km.
  • Road maintenance on a limited budget. If Blantyre City Council could only resurface 22 roads, the MST keeps every area from Limbe to Blantyre town reachable for the least total length of road to maintain.
  • Emergency access. During heavy rains, when some roads flood or wash away, the MST shows a minimal backbone that must stay open so that every area, including QECH, can still be reached.

What the MST does not represent: it is not a set of shortest routes. In the MST the only route from Blantyre CBD to Limbe is Blantyre CBD → Mandala → QECH → Chichiri → Ginnery Corner → Makata → Kanjedza → Chinyonga → Mpingwe → Limbe, which is 13.7 km, compared with the 9.1 km found by Dijkstra. The MST minimises the total length of the whole network; Dijkstra minimises the length of one journey.

7. Which MST algorithm we would use, and why Q7 · 10 marks

KruskalPrim
IdeaSort all roads by length. Add each road unless it joins two places that are already connected (it would make a cycle).Start from one place. Repeatedly add the shortest road from the tree to a place not yet in the tree.
Data structureSorted edge list + union–find (disjoint sets)Priority queue + adjacency list
TimeO(E log E)O(E log V) with a binary heap; O(V²) with an array
Best forSparse graphs, data given as an edge listDense graphs, data given as an adjacency matrix
On our graph37 × log₂37 ≈ 193 basic steps37 × log₂23 ≈ 167 basic steps

We would use Kruskal's algorithm, for these reasons:

  1. The graph is sparse (37 edges, density 0.15). Kruskal's cost depends on sorting the edges, which is cheap when there are few of them. The O(V²) array version of Prim, which suits dense graphs, would waste work here. For a graph this small the binary-heap versions of both algorithms are practically equal in speed, so the decision comes down to the next points.
  2. Our data is already an edge list. The file blantyre_roads.csv is a list of roads with lengths, which is exactly Kruskal's input. No adjacency structure is needed.
  3. It is easy to explain and check by hand. Kruskal processes roads from shortest to longest and makes one yes/no decision for each, as in the trace below. This matches how a planner would think: “lay the cheapest links first, unless the two places are already connected”.
  4. It handles a disconnected network gracefully. If floods cut the network into pieces (test T18), Kruskal returns a minimum spanning forest, one tree per piece, without any change. Prim only builds the tree of the piece containing its start place.

We implemented both algorithms to confirm the answer. Prim gives the same 39.3 km total from every one of the 23 possible start places (test T24).

// graph.hpp - Weighted undirected graph of places in Blantyre city, with
// Dijkstra's shortest path and two Minimum Spanning Tree algorithms
// (Prim and Kruskal).
#pragma once

#include <algorithm>
#include <fstream>
#include <functional>
#include <limits>
#include <map>
#include <queue>
#include <sstream>
#include <stdexcept>
#include <string>
#include <tuple>
#include <vector>

namespace mw {

const long long INF = std::numeric_limits<long long>::max() / 4;

struct Edge {
    int u, v;
    long long w;
};

class Graph {
public:
    // Add a place if it is new; return its index either way.
    int addNode(const std::string& name) {
        auto it = index_.find(name);
        if (it != index_.end()) return it->second;
        int id = static_cast<int>(names_.size());
        names_.push_back(name);
        index_[name] = id;
        adj_.emplace_back();
        return id;
    }

    void addEdge(const std::string& a, const std::string& b, long long w) {
        if (w < 0) throw std::invalid_argument("Negative distance on road " + a + " - " + b +
                                                ": Dijkstra needs non-negative weights");
        if (a == b) throw std::invalid_argument("Self loop on " + a + " is not allowed");
        int u = addNode(a), v = addNode(b);
        adj_[u].push_back({v, w});
        adj_[v].push_back({u, w});
        edges_.push_back({u, v, w});
    }

    // Load "place_a,place_b,metres" lines. Blank lines and lines starting with # are skipped.
    static Graph fromCsv(std::istream& in) {
        Graph g;
        std::string line;
        int lineNo = 0;
        while (std::getline(in, line)) {
            ++lineNo;
            if (!line.empty() && line.back() == '\r') line.pop_back();
            if (line.empty() || line[0] == '#') continue;
            std::stringstream ss(line);
            std::string a, b, w;
            if (!std::getline(ss, a, ',') || !std::getline(ss, b, ',') || !std::getline(ss, w)) {
                throw std::runtime_error("Line " + std::to_string(lineNo) + ": expected place_a,place_b,metres");
            }
            long long metres;
            try {
                size_t used = 0;
                metres = std::stoll(w, &used);
                if (used != w.size()) throw std::invalid_argument("trailing");
            } catch (const std::exception&) {
                throw std::runtime_error("Line " + std::to_string(lineNo) + ": bad distance '" + w + "'");
            }
            g.addEdge(a, b, metres);
        }
        return g;
    }

    static Graph fromFile(const std::string& path) {
        std::ifstream f(path);
        if (!f) throw std::runtime_error("Cannot open " + path);
        return fromCsv(f);
    }

    int size() const { return static_cast<int>(names_.size()); }
    const std::vector<Edge>& edges() const { return edges_; }
    const std::string& name(int id) const { return names_.at(id); }
    const std::vector<std::pair<int, long long>>& neighbours(int u) const { return adj_.at(u); }

    int id(const std::string& name) const {
        auto it = index_.find(name);
        if (it == index_.end()) throw std::out_of_range("Unknown place: " + name);
        return it->second;
    }
    bool has(const std::string& name) const { return index_.count(name) > 0; }

private:
    std::vector<std::string> names_;
    std::map<std::string, int> index_;
    std::vector<std::vector<std::pair<int, long long>>> adj_;
    std::vector<Edge> edges_;
};

// ---------------------------------------------------------------- Dijkstra

struct DijkstraResult {
    std::vector<long long> dist;  // dist[v] = shortest distance in metres from source (INF if unreachable)
    std::vector<int> prev;        // prev[v] = previous place on the shortest path (-1 if none)
};

// One step of the algorithm, recorded for the dry run trace.
struct TraceStep {
    int settled;                                   // place removed from the queue and finalised
    long long settledDist;
    std::vector<std::tuple<int, long long, long long>> relaxed;  // (place, old dist, new dist)
};

// Dijkstra with a binary heap (std::priority_queue): O((V + E) log V).
inline DijkstraResult dijkstra(const Graph& g, int source, std::vector<TraceStep>* trace = nullptr) {
    int n = g.size();
    if (source < 0 || source >= n) throw std::out_of_range("Source index out of range");
    DijkstraResult r{std::vector<long long>(n, INF), std::vector<int>(n, -1)};
    std::vector<bool> done(n, false);
    using Item = std::pair<long long, int>;  // (distance, place)
    std::priority_queue<Item, std::vector<Item>, std::greater<Item>> pq;

    r.dist[source] = 0;
    pq.push({0, source});
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (done[u]) continue;  // stale queue entry
        done[u] = true;
        TraceStep step{u, d, {}};
        for (auto [v, w] : g.neighbours(u)) {
            if (done[v]) continue;
            if (d + w < r.dist[v]) {
                step.relaxed.emplace_back(v, r.dist[v], d + w);
                r.dist[v] = d + w;
                r.prev[v] = u;
                pq.push({r.dist[v], v});
            }
        }
        if (trace) trace->push_back(step);
    }
    return r;
}

// Rebuild the path source -> target from prev[]. Empty if unreachable.
inline std::vector<int> buildPath(const DijkstraResult& r, int target) {
    std::vector<int> path;
    if (r.dist.at(target) >= INF) return path;
    for (int v = target; v != -1; v = r.prev[v]) path.push_back(v);
    std::reverse(path.begin(), path.end());
    return path;
}

// ---------------------------------------------------------------- MST

struct MstResult {
    std::vector<Edge> edges;
    long long total = 0;
    bool spanning = false;  // false if the graph is disconnected (then it is a forest)
};

// Disjoint Set Union with path compression and union by rank.
class DSU {
public:
    explicit DSU(int n) : parent_(n), rank_(n, 0) {
        for (int i = 0; i < n; ++i) parent_[i] = i;
    }
    int find(int x) { return parent_[x] == x ? x : parent_[x] = find(parent_[x]); }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false;
        if (rank_[a] < rank_[b]) std::swap(a, b);
        parent_[b] = a;
        if (rank_[a] == rank_[b]) ++rank_[a];
        return true;
    }

private:
    std::vector<int> parent_, rank_;
};

// Kruskal: sort edges by weight, add each edge that joins two different components. O(E log E).
inline MstResult kruskal(const Graph& g) {
    MstResult r;
    std::vector<Edge> es = g.edges();
    std::stable_sort(es.begin(), es.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
    DSU dsu(g.size());
    for (const Edge& e : es) {
        if (dsu.unite(e.u, e.v)) {
            r.edges.push_back(e);
            r.total += e.w;
        }
    }
    r.spanning = g.size() > 0 && static_cast<int>(r.edges.size()) == g.size() - 1;
    return r;
}

// Prim: grow one tree from `start`, always taking the cheapest edge leaving it. O(E log V).
inline MstResult prim(const Graph& g, int start = 0) {
    MstResult r;
    int n = g.size();
    if (n == 0) return r;
    std::vector<bool> inTree(n, false);
    using Item = std::tuple<long long, int, int>;  // (weight, from, to)
    std::priority_queue<Item, std::vector<Item>, std::greater<Item>> pq;
    pq.push({0, -1, start});
    while (!pq.empty()) {
        auto [w, from, to] = pq.top();
        pq.pop();
        if (inTree[to]) continue;
        inTree[to] = true;
        if (from != -1) {
            r.edges.push_back({from, to, w});
            r.total += w;
        }
        for (auto [v, wv] : g.neighbours(to))
            if (!inTree[v]) pq.push({wv, to, v});
    }
    r.spanning = static_cast<int>(r.edges.size()) == n - 1;
    return r;
}

}  // namespace mw

#include <iostream>
#include <sstream>

#include "graph.hpp"

using namespace mw;

// Metres to km with one decimal, e.g. 1500 -> "1.5".
static std::string km(long long m) {
    if (m >= INF) return "inf";
    std::ostringstream o;
    o << std::fixed << std::setprecision(1) << m / 1000.0;
    return o.str();
}

static void printPath(const Graph& g, const std::string& from, const std::string& to, bool withTrace) {
    int s = g.id(from), t = g.id(to);
    std::vector<TraceStep> trace;
    DijkstraResult r = dijkstra(g, s, withTrace ? &trace : nullptr);

    if (withTrace) {
        std::cout << "Dry run of Dijkstra from " << from << "\n";
        int step = 1;
        for (const TraceStep& st : trace) {
            std::cout << "Step " << std::setw(2) << step++ << ": settle " << g.name(st.settled)
                      << " (" << km(st.settledDist) << " km)";
            if (st.relaxed.empty()) std::cout << ", no updates";
            for (auto [v, oldD, newD] : st.relaxed)
                std::cout << "\n          update " << g.name(v) << ": " << km(oldD) << " -> " << km(newD);
            std::cout << "\n";
            if (st.settled == t) {
                std::cout << "Target " << to << " settled, so its distance is final.\n";
                break;
            }
        }
        std::cout << "\n";
    }

    std::vector<int> path = buildPath(r, t);
    if (path.empty()) {
        std::cout << "No route from " << from << " to " << to << "\n";
        return;
    }
    std::cout << "Shortest route " << from << " -> " << to << ": " << km(r.dist[t]) << " km\n";
    for (size_t i = 0; i < path.size(); ++i) {
        std::cout << (i ? " -> " : "  ") << g.name(path[i]);
    }
    std::cout << "\n";
}

static void printAll(const Graph& g, const std::string& from) {
    DijkstraResult r = dijkstra(g, g.id(from));
    std::cout << "Shortest distances from " << from << ":\n";
    for (int v = 0; v < g.size(); ++v) {
        std::cout << "  " << std::left << std::setw(15) << g.name(v) << std::right << std::setw(6)
                  << km(r.dist[v]) << " km   via ";
        std::vector<int> p = buildPath(r, v);
        for (size_t i = 0; i < p.size(); ++i) std::cout << (i ? " > " : "") << g.name(p[i]);
        std::cout << "\n";
    }
}

static void printMst(const Graph& g, const std::string& algo) {
    MstResult m;
    if (algo == "prim") m = prim(g);
    else if (algo == "kruskal") m = kruskal(g);
    else throw std::invalid_argument("MST algorithm must be prim or kruskal");
    std::cout << "Minimum spanning tree (" << algo << "), in the order edges were added:\n";
    for (const Edge& e : m.edges)
        std::cout << "  " << std::left << std::setw(15) << g.name(e.u) << " - " << std::setw(15) << g.name(e.v)
                  << std::right << std::setw(5) << km(e.w) << " km\n";
    std::cout << "Edges: " << m.edges.size() << ", total length: " << km(m.total) << " km"
              << (m.spanning ? "" : "  (graph is disconnected: this is a spanning forest)") << "\n";
}

static void printPlaces(const Graph& g) {
    std::cout << g.size() << " places, " << g.edges().size() << " roads\n";
    for (int v = 0; v < g.size(); ++v) std::cout << "  " << g.name(v) << "\n";
}

static void interactive(const Graph& g) {
    while (true) {
        std::cout << "\n1) Shortest route  2) Route with dry run  3) Distances from a place\n"
                     "4) MST (Prim)  5) MST (Kruskal)  6) List places  0) Quit\nChoice: ";
        std::string c;
        if (!std::getline(std::cin, c) || c == "0") return;
        try {
            std::string a, b;
            if (c == "1" || c == "2" || c == "3") {
                std::cout << "From place: ";
                std::getline(std::cin, a);
            }
            if (c == "1" || c == "2") {
                std::cout << "To place: ";
                std::getline(std::cin, b);
            }
            if (c == "1") printPath(g, a, b, false);
            else if (c == "2") printPath(g, a, b, true);
            else if (c == "3") printAll(g, a);
            else if (c == "4") printMst(g, "prim");
            else if (c == "5") printMst(g, "kruskal");
            else if (c == "6") printPlaces(g);
            else std::cout << "Unknown choice\n";
        } catch (const std::exception& e) {
            std::cout << "Error: " << e.what() << "\n";
        }
    }
}

int main(int argc, char** argv) {
    std::vector<std::string> args(argv + 1, argv + argc);
    std::string data = "data/blantyre_roads.csv";
    if (args.size() >= 2 && args[0] == "--data") {
        data = args[1];
        args.erase(args.begin(), args.begin() + 2);
    }
    try {
        Graph g = Graph::fromFile(data);
        if (args.empty()) interactive(g);
        else if (args[0] == "path" && args.size() == 3) printPath(g, args[1], args[2], false);
        else if (args[0] == "trace" && args.size() == 3) printPath(g, args[1], args[2], true);
        else if (args[0] == "all" && args.size() == 2) printAll(g, args[1]);
        else if (args[0] == "mst") printMst(g, args.size() > 1 ? args[1] : "kruskal");
        else if (args[0] == "places") printPlaces(g);
        else {
            std::cerr << "Usage: roads [--data FILE] path|trace <From> <To> | all <From> | mst [prim|kruskal] | places\n";
            return 2;
        }
    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << "\n";
        return 1;
    }
    return 0;
}
